CLIPBRIEF · EFFECTIVE 2026-08-19

Privacy Policy

This policy reflects ClipBrief v1.0.0 exactly.

Introduction and single purpose

ClipBrief saves text that you intentionally select on the active web page into a local research brief, with a source URL and optional tag.

Information we collect

Only when you select text on an HTTP(S) page and open ClipBrief, it reads that selection, page URL, page title, and your optional tag. When you save, those details and a save time are stored locally in Chrome extension storage.

Information we do not collect

ClipBrief does not collect accounts, credentials, cookies, form data, browsing history, payments, analytics, advertising identifiers, telemetry, or information from pages where you did not invoke the extension.

Use, storage, and retention

These data power your clip list and Markdown export only. v1.0.0 makes no network requests and uses no developer server or third-party service. Data remains locally until you delete it, clear all clips, or uninstall the extension.

Sharing and security

ClipBrief does not sell, rent, share, or use data for advertising. It includes no remote code. You may remove individual clips or clear all locally saved clips at any time.

Children, changes, and contact

ClipBrief is not directed to children. A release that adds sync, accounts, analytics, AI, or data transmission will update this policy and required disclosures before release. Before publishing, CUTNOS will add a public support contact here.

Chrome Web Store Limited Use

ClipBrief v1.0.0 does not use Google APIs. If a future version accesses Google API user data, its use will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
